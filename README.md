# Password-strength-checker
A beginner Python project that checks how strong a password is.
What it does: It checks 6 rules including length up to 8 or more characters, lowercase letter, uppercase letter, number, symbol, and whether the password is on a list of common passwords. It then prints  either Weak, Medium, or Strong and tells the user what to improve.
How to Run: Open the file in Google Colab (or any Python environment), run it, and type a password when asked.
What I learned: - How to use input(), if/else, and lists in Python
                - Using conditions to check password requirements
                - How to find and fix a bug in my own code
Note:- I built this to learn Python and basic security, using AI tools to help me learn and fix errors.
